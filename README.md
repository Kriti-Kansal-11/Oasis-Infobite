TEMPERATUE CONVERTER:
This project is a Temperature Converter application developed in HTML, CSS, and JavaScript. It allows users to convert temperatures between Celsius, Fahrenheit, and Kelvin with a user-friendly interface.
Key features include:
Input Fields: Users can enter a temperature value in any one unit (Celsius, Fahrenheit, or Kelvin).
Conversion Logic: Automatic conversion to the other two units upon input, utilizing JavaScript functions to handle the mathematical calculations.
Clear Button: Option to clear the input fields and reset the form.
Error Handling: Provides feedback if the user enters invalid data.
This project demonstrates interactive web development skills with JavaScript, focusing on event handling, conditional statements, and form validation.
